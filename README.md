# 🎮 Auto Steam Rent — Плагин для FunPay Cardinal

## 📋 Описание

**Auto Steam Rent** — плагин для [FunPay Cardinal](https://github.com/sidor0912/FunPayCardinal), который полностью автоматизирует аренду Steam аккаунтов на FunPay. После оплаты покупатель мгновенно получает данные для входа и играет нужное время. По истечении срока аренды плагин автоматически меняет пароль — аккаунт возвращается в пул и готов к следующей аренде.

## 🌟 Возможности

| Функция | Описание |
|---------|----------|
| 🚀 Автовыдача | Данные для входа отправляются покупателю сразу после оплаты |
| ⏱ Гибкие сроки | Поддержка периодов: 1 ч, 2 ч, 3 ч, 6 ч, 12 ч, 1 день, 2 дня, 3 дня, 7 дней |
| 🔑 Steam Guard | Покупатель получает актуальный код командой `!code` в чате FunPay |
| ⏳ Время аренды | Покупатель может узнать оставшееся время командой `!time` |
| 🔄 Продление | Поддержка продления аренды командой `!extend` (опционально) |
| 🗂 Авто-лоты | Лоты автоматически выключаются при пустом складе и включаются при пополнении |
| 🎛 Управление лотами | Кнопки «Выкл все» / «Вкл все» для управления всеми лотами одним нажатием |
| 🔐 Смена пароля | После истечения аренды пароль автоматически меняется на новый |
| 🔔 Уведомления | Уведомления в Telegram об аренде, возврате, ошибках |
| 📊 Статистика | Детальная статистика по каждому аккаунту и за периоды |
| 🩺 Диагностика | При старте плагин проверяет maFile, Playwright и лоты — сообщает о проблемах |
| 💾 Персистентность | Все данные сохраняются между перезапусками бота |
| ⚙️ Управление через Telegram | Полная настройка плагина через Telegram-бота |

## 📦 Установка

1. Скачайте файл `auto_steam_rent.py` из этого репозитория.
2. Откройте чат с ботом FunPay Cardinal в Telegram.
3. Введите команду: `/upload_plugin`.
4. Отправьте скачанный файл плагина боту.
5. Перезапустите бота.

При первом запуске плагин автоматически установит необходимые зависимости (`aiohttp`, `playwright`, `pysteamauth`, `rsa`, `pytz`) и скачает браузер Chromium для Playwright.

> **Примечание:** Установка зависимостей при первом запуске может занять до нескольких минут.

## ⚙️ Настройка

### Быстрый старт

1. Откройте Telegram-бота FunPay Cardinal.
2. Введите команду: `/auto_steam_rent`.
3. Перейдите в **Аккаунты** → **Добавить аккаунт**.
4. Укажите тег аккаунта, логин, пароль и загрузите maFile (файл Steam Guard).
5. Убедитесь, что тег аккаунта совпадает с тегом лота на FunPay.
6. Включите плагин кнопкой 🟢/🔴 **Включён**.
7. Готово — плагин начнёт обрабатывать заказы автоматически.

### Добавление аккаунта

- **Тег** — произвольное имя (латиница, например `game1`). Должен совпадать с тегом лота на FunPay.
- **Логин** — логин Steam аккаунта.
- **Пароль** — текущий пароль Steam аккаунта.
- **maFile** — файл `*.maFile` из Steam Desktop Authenticator (SDA).

> ⚠️ **Важно:** Не устанавливайте passkey в SDA — плагин не сможет добавить зашифрованный maFile.

### Привязка лота к аккаунту

Тег аккаунта и тег лота на FunPay должны совпадать. Тег лота указывается в описании лота в формате `[тег]`. Например, если тег аккаунта — `game1`, добавьте `[game1]` в описание лота.

## 💬 Команды покупателя в чате

| Команда | Описание |
|---------|----------|
| `!code` / `!steamguard` | Получить актуальный Steam Guard код |
| `!time` | Узнать оставшееся время аренды |
| `!extend` | Продлить аренду (если включено продавцом) |
| `!stock` | Проверить наличие свободных аккаунтов |

## 🔧 Технические детали

- **Хранение данных:** Все данные сохраняются в:
  ```
  storage/plugins/auto_steam_rent/accounts.json
  storage/plugins/auto_steam_rent/orders.json
  storage/plugins/auto_steam_rent/settings.json
  ```
- **Потокобезопасность:** Все операции с аккаунтами и заказами защищены `threading.Lock`.
- **Атомарные сохранения:** JSON-файлы сохраняются через `tempfile` + `os.replace` — данные не теряются при сбое.
- **Steam Guard:** TOTP-коды генерируются локально из maFile без обращения к Steam.
- **Смена пароля:** Для смены пароля используется Playwright (Chromium) — автоматически управляет Steam Guard при входе.
- **Авто-лоты:** При изменении статуса аккаунта переключение лотов выполняется в отдельном потоке, не блокируя основной цикл.
- **Защита от дублей:** Каждый заказ обрабатывается только один раз (`MAX_PROCESSED_IDS = 1000`).
- **История заказов:** Хранятся последние 500 заказов за 14 дней.
- **Cooldown кодов:** Запросы Steam Guard кода ограничены (5 секунд между запросами).
