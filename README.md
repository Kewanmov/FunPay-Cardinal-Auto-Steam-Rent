# 🎮 Auto Steam Rent — плагин для FunPay Cardinal

## 📋 Описание

**Auto Steam Rent** — плагин для [FunPay Cardinal](https://github.com/sidor0912/FunPayCardinal), который автоматизирует аренду Steam-аккаунтов на FunPay. После оплаты покупатель мгновенно получает логин и пароль, а актуальный Steam Guard код запрашивает командой `!code` прямо в чате. По истечении срока аренды плагин сам меняет пароль аккаунта — он возвращается в пул и готов к следующей аренде.

📖 Подробный гайд по использованию — в [USAGE.md](USAGE.md).

## 🛠 Поддержка

Плагин поддерживается не очень активно — обновления и ответы на вопросы выходят нерегулярно, но проект не заброшен. Личная помощь с настройкой под конкретный магазин не оказывается — вся нужная информация есть в этом README и в [USAGE.md](USAGE.md). С багами и предложениями — через Issues в этом репозитории.

## 📦 Установка

1. Скачайте `auto_steam_rent.py` из этого репозитория.
2. Откройте Telegram-бота FunPay Cardinal.
3. Введите команду `/upload_plugin` и отправьте боту скачанный файл.
4. Перезапустите бота.

При первом запуске плагин сам установит зависимости (`aiohttp`, `playwright`, `pysteamauth`, `rsa`, `pytz`) и скачает Chromium для Playwright — это может занять несколько минут.

## ⚙️ Быстрый старт

1. Откройте Telegram-бота и введите `/auto_steam_rent`.
2. **Аккаунты → Добавить аккаунт** — укажите логин, пароль, доступные периоды аренды и загрузите `.maFile`.
3. **Лоты → Добавить лот** — введите ID лота (или ссылку на него), отметьте один или несколько аккаунтов для пула этого лота, выберите период аренды.
4. Включите плагин кнопкой 🔴/🟢 **Авто-выдача** в главном меню.
5. Готово — новые заказы по этому лоту будут обрабатываться автоматически.

### Добавление аккаунта

- **Логин / пароль** — текущие данные входа в Steam.
- **Периоды аренды** — на какие сроки можно сдавать этот аккаунт (1ч, 24ч, 7 дней и т.д., либо своё значение). Это не просто фильтр в интерфейсе: при выдаче заказа плагин старается выбрать из пула аккаунт, у которого период лота входит в разрешённые.
- **maFile** — файл `*.maFile` из Steam Desktop Authenticator (SDA).

> ⚠️ Не устанавливайте passkey в SDA — плагин не сможет прочитать зашифрованный maFile.

### Привязка лота к аккаунтам

Привязка настраивается **только через меню бота**, редактировать описание лота на FunPay не нужно:

**🔗 Лоты → ➕ Добавить лот** → ввести ID лота (число или ссылка вида `funpay.com/lots/offer?id=...`) → отметить чекбоксами один или несколько аккаунтов (пул для этого лота) → выбрать период аренды.

Если в пуле несколько аккаунтов, при новом заказе плагин выдаёт первый свободный.

## 🔧 Технические детали

- **Хранение данных** — JSON-файлы в:
  ```
  storage/plugins/auto_steam_rent/accounts.json
  storage/plugins/auto_steam_rent/orders.json
  storage/plugins/auto_steam_rent/settings.json
  ```
- **Потокобезопасность** — все операции с аккаунтами и заказами защищены `threading.Lock`; смена пароля одного аккаунта не может запуститься дважды параллельно (вручную и в фоне одновременно).
- **Атомарные сохранения** — JSON пишется через `tempfile` + `os.replace`; запись на диск блокируется при выгрузке плагина, чтобы не перезаписать данные новой копии устаревшими.
- **Steam Guard** — TOTP-коды генерируются локально из `maFile`, без обращения к Steam API.
- **Смена пароля** — через Playwright (Chromium): плагин реально заходит в Steam и проходит мобильное подтверждение.
- **Авто-лоты** — переключение лотов на FunPay выполняется в отдельном потоке, не блокируя основной цикл бота.
- **Защита от дублей** — каждый заказ обрабатывается только один раз; при сбое обработки заказ переобрабатывается при следующем событии, а не теряется молча.
- **История заказов** — хранятся последние 500 заказов за 14 дней.
- **Cooldown кодов** — запросы Steam Guard кода ограничены по частоте (5 секунд между запросами).
